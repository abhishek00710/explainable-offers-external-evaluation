# Provenance and artifact integrity

## Source classifier

The six files under `Sources/OfferCore/` are exact copies of the original research repository's `artifact/Validation/Sources/OfferCore/` at the annotated `v1.0.0` tag. The tag resolves to source commit `ca33e4c59510dd632482b8a5bfa2512af67e3d3f`. Their SHA-256 digests are recorded in `Results/source-digests.json` and match the contents of the official GitHub tag archive. `Scripts/reproduce.sh` checks out this tag and compares all six files byte-for-byte before running the evaluation.

The public-source repository is [abhishek00710/explainable-offers-research](https://github.com/abhishek00710/explainable-offers-research), tag [v1.0.0](https://github.com/abhishek00710/explainable-offers-research/tree/v1.0.0). The original release archive and tag are not modified by this supplement.

## Dataset

The external dataset is MoneyData v1, DOI `10.17632/dnxtg6n4rv.1`, downloaded from the official Mendeley Data record. The source workbook's SHA-256 is included in `Results/dataset-summary.json`. The workbook is not bundled. No transaction descriptions, account fields, row-level labels, or row-level predictions are stored in this repository. The preparation step writes a temporary description/label TSV only during a run and removes it on exit.

The independently authored mapping between source labels and the five prototype categories is fixed in `protocol.md` and in the preparation script. It was not generated by a classifier. Classifier rules were not tuned using the external labels.

## Preserved measurements

The aggregate CSV files, current audit, console log, environment record, and frozen crosswalk are preserved as the evaluated evidence. The supplement adds documentation and reproduction safeguards without changing the classification policies or reported metric values. `Results/preservation-check.txt` verifies the original repository's two release manifests and the six copied source files. `Results/publication-audit.txt` records the disclosure scan and repository inventory at preparation time.
